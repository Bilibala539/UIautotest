# Swan 用例对象模型与调用关系规划（2026-10-13，用户设计拍板）

> 核心理念：**用户对象是一等公民**——`self.userA = self.users("swanuserA")` 实例化一个
> 用户，其全部用户信息（电话/密码/用户名/包名/绑定设备…）保存在该对象的**信息字典**
> 中；用例全程 `self.userA.xxx()` 直调（业务方法与基础操作无差别），**不存在
> self.aw 中间层**。`swanuserA`/`swanuserB` 是两个独立的用户对象。

## 一、类图（组合与继承关系）

```
┌─────────────────────────────────────────────────────────────┐
│ 用例类 TestXxx(SwanPlayerRegressionMixin, BaseTest)          │
│                                                             │
│   self.userA ──────────────┐        （组合：用例持有用户对象）│
└────────────────────────────┼────────────────────────────────┘
                             ▼
┌─────────────────────────────────────────────────────────────┐
│ 用户对象 SwanUser（utils/user.py）                           │
│                                                             │
│  info 字典（用户信息，每对象一份）：                          │
│    name      = "swanuserA"    ← 实例标识                    │
│    phone     = "13555555555"  ← env SWAN_PHONE              │
│    password  = "…"            ← env SWAN_PASSWORD           │
│    package   = "com.swan.network"                           │
│    device    = "Libretto_0E00" ← 绑定 rig（可扩展键）        │
│                                                             │
│  ┌───────────────────────────────────────────────┐          │
│  │ business = SwanBusiness（__getattr__ 代理目标）│          │
│  │   ↑ MRO: CommonBusinessMixin                  │          │
│  │         → FlutterBaseAW → AndroidBaseAW       │          │
│  │         → AWBase                              │          │
│  └───────────────────────────────────────────────┘          │
└─────────────────────────────────────────────────────────────┘
                             ▼
┌─────────────────────────────────────────────────────────────┐
│ 驱动层 FlutterAndroidDriver（adb 直连真机）                   │
└─────────────────────────────────────────────────────────────┘
```

关系清单：
| 关系 | 双方 | 说明 |
|---|---|---|
| 组合（持有） | 用例类 → SwanUser | `self.userA`，工厂按 key 缓存（同 key 同实例，登录态跨用例保持） |
| 工厂创建 | TTUsersFactory → SwanUser | `users("swanuserA")` / `users("swanuserB")` = 两个独立用户对象、两份 info |
| 继承 | SwanBusiness → CommonBusinessMixin → FlutterBaseAW → AndroidBaseAW → AWBase | 业务方法与基础操作集于一身——**这是 userA 能直调一切的机制** |
| 代理 | SwanUser.__getattr__ → business | `userA.playMusic()` 无需在 User 类声明，自动落到 SwanBusiness |
| 委托 | 回归 mixin → 用户对象 | mixin 前置/清理方法内部经 `self.userA.xxx()` 操作 |

## 二、调用关系（用例视角）

```python
class TestXxx(SwanPlayerRegressionMixin, BaseTest):

    def setup(self) -> None:
        """实例化用户对象。"""
        self.userA = self.users("swanuserA")

    def test_xxx(self):
        # ① 业务方法（__getattr__ 代理 → SwanBusiness）
        self.userA.login_by_sms(self.userA.phone)     # 凭据从 userA 自身取
        self.userA.play_music()                        # 业务动作
        # ② 基础操作（继承 → AWBase，同一实例）
        self.userA.click_image(SWAN_TAB_PLATFORM)      # 无 self.aw 前缀
        # ③ 生效验证
        self.userA.assert_playing()

    def teardown(self) -> None:
        self.userA.go_home()                           # 收尾
```

- **信息访问**：`userA.phone` / `userA.password` / `userA.package` / `userA.info["device"]`
- **多用户**：`userB = self.users("swanuserB")`——独立对象/独立 info，双用户交互用例
  （如 A 发消息 B 断言收到）天然支持
- **mixin 前置**：`self._preset_playing("speaker")`（mixin 方法内部同样经
  `self.userA.xxx()` 操作，mixin 与用例共享同一个 userA 实例）

## 三、mixin 调用关系（共用前置/清理）

```
用例 TestXxx ──继承──> SwanPlayerRegressionMixin
                         │
                         ├─ setup()   设置 self.userA（与用例 setup 等价，兜底）
                         ├─ _preset_playing(dt)   登录→导航→发起播放
                         │    └─ 内部全部 self.userA.xxx()
                         └─ teardown()  G3/G4 清理链
                              └─ 内部全部 self.userA.xxx()
```

## 四、用户信息字典的填充规则

| 键 | 来源 | 说明 |
|---|---|---|
| name | users() 的 key（"swanuserA"） | 实例标识 |
| phone | env `SWAN_PHONE`（只读 property，实时真值） | 13555555555 |
| password | env `SWAN_PASSWORD`（只读 property） | 密码域用例用 |
| package | env `SWAN_PACKAGE` | com.swan.network |
| device | env `SWAN_DEVICE_NAME` | 绑定 rig 音箱名 |
| （可扩展） | 后续新增用户属性一律进 info 字典 | 禁散落为裸属性 |

多用户规划：`swanuserA`（主测号 135）为主；`swanuserB` 及以后=同账号或第二测试
账号，info 键结构相同、值不同——**凭据一律环境变量注入，不写死用例**。

## 五、红线（本模型下的禁令）

- ❌ `self.aw` 中间层（已全仓消灭；新代码出现即违规）
- ❌ `self.user`/`self.phone` 等散落属性（信息只在 userA 对象上）
- ❌ 用户信息写死进用例（电话/密码/设备名一律 `userA.phone` 等对象访问）
- ❌ mixin/setup 双处重复实例化（setup 一行实例化，mixin setup 仅兜底兼容）
