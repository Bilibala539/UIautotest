# Swan 测试用例文件规范（强制遵守）

> 适用范围：Swan 项目（tests/flutter/）。其他项目参照 CLAUDE.md 规则 8 与本模板。
> 2026-10-09 修订：去除 POPO 遗留条款，对齐现行实践；重申"一用例一文件"。

## 强制条款

1. **一用例一文件一 test 方法（铁律）**：每个用例 .py 文件**有且仅有一个 `test_` 方法**；不同测试场景各自独立成文件。同一场景的数据变体用 `@pytest.mark.parametrize` 挂在该方法上。适用全工程（web/android/flutter），例外仅限 `tests/flutter/test_case_driver.py`（平台 YAML 用例执行载体）（CLAUDE.md 规则 8）
2. **固定方法名**：用例类中必须有 `setup()` 和 `teardown()` 方法，**必须使用这两个名字**（conftest 的 `_auto_test_lifecycle` 自动调用），不要改成 `setup_method` 或其他变体
3. **禁止 Page Object 模式**：本工程不使用 Page Object 管理页面，业务流程通过业务方法编排（如 `self.user.start_play()`、`self.user.select_device()`）
4. **用户实例化只在 setup()**：`self.user = self.users("swan")`（无需手动 login）；`teardown()` 只写自定义清理（无需手动 logout）
5. **基础操作不堆在用例里**：缺业务动作 → 加到 `SwanBusiness`（utils/aw/business/swan.py）；用例间共用的前置/清理编排 → 放业务层 `utils/aw/business/swan_regression.py`（mixin），不在用例间复制粘贴
6. **定位与断言**：图像模板 > OCR 文本；accessibility key 仅限探索辅助（explorer），运行时用例禁止 key（CLAUDE.md 规则 2）；断言以可观察状态收尾，禁止"只断言没异常"

## 标准测试用例模板

```python
"""
Swan 回归·<域>：<用例名>（回归用例 <编号>）。

用例 -> AW 映射（docs/Swan回归用例AW实现方案.md §2.3 域N）：
- <步骤/断言对应关系>
清理（G3/G4）：由 mixin teardown 承担（关弹层 -> 尽力暂停 -> 收播放页 -> 回首页）。
"""
from __future__ import annotations

import os

import pytest

from conftest import BaseTest
from utils.aw.business.swan_regression import SwanPlayerRegressionMixin

_platform = os.environ.get("PLATFORM", "web").strip().lower()
_has_phone = bool(os.environ.get("SWAN_PHONE", "").strip())

pytestmark = pytest.mark.skipif(
    _platform != "flutter" or not _has_phone,
    reason="Swan 用例需要 PLATFORM=flutter 和 SWAN_PHONE",
)


class TestXxx(SwanPlayerRegressionMixin, BaseTest):
    """<用例名>。"""

    def setup(self):
        """实例化用户（登录/导航由 mixin 前置方法按需执行）。"""
        self.user = self.users("swan")
        self.aw = self.user.aw

    def test_xxx_scenario(self):
        """<测试场景描述>。"""
        self._preset_playing("speaker")   # 共用前置：登录 -> 导航 -> 发起播放
        self.user.assert_playing()        # 业务方法断言收尾

    def teardown(self):
        """G3/G4 清理由 mixin teardown 承担；此处只写本用例自定义清理。"""
```

## 禁止事项

- ❌ 一个 py 文件多个 test 方法（铁律，CLAUDE.md 规则 8）
- ❌ `setup_method` / `teardown_method` 等变体命名
- ❌ `LoginPage` 式 Page Object
- ❌ 用例中手写 login()/logout() 幂等前置（复用业务层/ mixin）
- ❌ 用例里堆基础操作序列（该沉淀进 SwanBusiness 的沉淀进去）
- ❌ try/except 吞断言失败
