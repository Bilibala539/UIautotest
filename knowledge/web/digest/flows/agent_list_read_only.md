# Agents 列表只读流程

## 目标

验证有效会话下的 M8 Agents 列表可访问、可筛选、可分页，且不改变 Agent 或远端系统状态。

## 前置条件

- 测试账号通过环境变量提供。
- 浏览器使用 1440×1200 视口。
- 不点击 New Agent、Import、Sync fleet、Delete 或任何运行类操作。

## 流程

1. 访问 [[login_page]] 对应路由。
2. 输入环境变量中的测试账号，提交登录。
3. 断言 [[agents_page]] 的 `m8-agents-page` 可见。
4. 断言汇总区、筛选区和表格容器可见。
5. 在 `m8-agents-filter-search` 输入一个非破坏性搜索词，断言筛选状态生效。
6. 清空搜索词；仅在 Next 可用时进入下一页，断言分页状态变化后返回第一页。
7. 清理浏览器会话。

## 断言

- 页面和表格使用 `data-testid` 可定位。
- 不断言动态总数、真实 Agent 名称、实时失败次数或成本指标。
- 失败时保存截图、当前 URL、可见文本摘要和浏览器控制台日志。
