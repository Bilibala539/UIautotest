# 设备管理 (feature_设备管理)

## 功能定义

设备列表页（已绑定设备的卡片管理）、添加设备（BLE/WiFi 双通道配网）、设备设置族、固件升级、远程控制。

## 包含页面

| 页面 | 角色 | 状态 |
|---|---|---|
| `[[swan_设备页]]` | 设备 Tab 主页 | 页面 |

缺口：添加设备 `/device/add`、BLE/WiFi 配网、设备设置族（5+ 页）、兼容机型、远程控制面板。多数入口依赖已绑定真实音箱设备；无设备时部分页面不可达。

## 包含 flow

- （待建）flow_设备_查看设备列表
- （待建）flow_设备_进入设备设置（依赖硬件）

## 边界与危险操作

- 固件升级：⛔ 不可逆，只断言入口存在。
- 删除设备/解绑：测试环境可点但需自清理。
- RCHIVE DSP / AW 耳机 / 低音炮：依赖对应硬件，无硬件则只做入口断言。
