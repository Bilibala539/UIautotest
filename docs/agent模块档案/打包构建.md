## 1. 一句话职责

维护 .166 构建环境(C:\build-env 三件套)与打包脚本 scripts/build_swan_apk.py(拉源码→checkout→flutter build→sha256→POST /api/apks 登记),脚本保留本地直跑能力、将来直接作为 Jenkins 打包 job 的核心 step。

## 2. 数据表

平台侧 apks 表(本模块只写不建表;DDL 在 dashboard/server.py:352-364):

| 字段 | 类型 | 说明 |
|---|---|---|
| apk_id | TEXT PK | upsert 键,规则 `swan-<branch>-<shortsha7>-<yyyymmdd>`,必填(build_swan_apk.py:226) |

关联:runs.apk_id(老库轻量迁移 server.py:346-349)、pipeline_jobs.apk_id(server.py:777,786)。upsert 语义 ON CONFLICT(apk_id) DO UPDATE(server.py:941-949);无 DELETE 接口。

`server_type`(formal=正式服/test=测试服)与 `build_time`(构建完成时间,格式 %Y-%m-%d %H:%M:%S;--skip-build 时回落产物 mtime):两列由包管理 agent 加(2026-09-20,后端已接受);打包脚本 payload 相应带 server_type 键(build_swan_apk.py:253,--server-type 默认 test)与 build_time 键(:254)。

## 6. 关键业务规则与坑

1. **凭据与脱敏**:密码只在内存拼进 git URL(build_swan_apk.py:195-196,app/core 两仓),redact() 把密码字面量换 `***`、带凭据 URL 归一为 `git.hivi.com/...`(:70-76);所有子命令回显与输出先脱敏再落日志(:79-91)。绝不进命令行明文/git。
2. **.166 是运行面,本机是开发面**:.166 的 `python` 是 WindowsApps 占位符,远程一律 `py -3`。
3. **ssh+PowerShell 坑**:远程命令分号分隔、禁 &&;双引号会被剥、`$`/`()` 会被解析;sdkmanager 的 `platforms;android-34` 必须加引号否则分号被拆;.ps1 无 BOM UTF-8 中文注释会吞行(远程脚本别写中文)。
4. **仓库拓扑(2026-09-20 主会话实测)**:git.hivi.com/swan-app/swan-audio 是**组**不是仓库;真实仓为组内子项目 hivi-network-flutterapp(app)+hivi_network_flutter_core(core),app 的 pubspec.yaml 以 `path: ../hivi_network_flutter_core`(及 `.../packages/swan_third_party_login`)相对路径引用 core,故 core 必须检出到 src 同级且目录名精确一致。分支拓扑 dev/master/harmony(无 develop)。core 仓同样需要 GITLAB_BOT 权限(auto_tester 已是两仓 direct member)。
5. **Flutter 3.47 要求 SDK 36**,只装 android-34 不够(两套都装了)。
6. **Windows 只读 objects 坑**:git clone 出的 .git/objects 文件只读,`shutil.rmtree(ignore_errors=True)` 会静默残留半删除目录,且残留 .git 会让下次 ensure_src 误判"已 clone"走 fetch 路径失败;须用 force_rmtree(失败解除只读重删,build_swan_apk.py:148-154)。
7. **源码目录默认清理**(:299-300),登记的 file_path 必须指向归档 E:\swan-build\apks,不能指向 src 下产物;登记失败时产物保留(:292)。
8. **apk_id 必填且是 upsert 键**,分支空段会生成非法 id(register_apk.py 缺省补 manual)。
9. .166 纪律:绝不 kill 进程;只装新软件;不动 8080 平台/8081 mesh/18080 otp-gateway;不部署服务、不提交 git(主会话做)。
10. 自测路径:权限未通时 `--repo-url`/`--core-repo-url` 指本地裸仓 + `--only-checkout` 验证检出(不构建不登记);登记曾用一次性 mock(18099)验证,未污染真实平台。2026-09-20 --server-type+build_time+双仓+--notes 自测同法:临时 dashboard(--port 18091+--database 临时db)验证 201 落库 + mock(18092) 抓 body 断言;build_time 用假 flutter.bat(FLUTTER_HOME 经 .env.local 覆盖指向假目录)端到端覆盖构建路径、utime 定值产物覆盖 skip-build 路径;双仓用本地双裸仓(dev/master 预提交产物文件)验证 clone/切分支/补 clone/force_rmtree 双删/日志脱敏;/api/builds 用 mock Jenkins(18093 收 form 落盘)断言参数拼装(NOTES 两层编码)、400×3/503/502 三实例矩阵。临时件(目录/db/进程)每次测完即清。
