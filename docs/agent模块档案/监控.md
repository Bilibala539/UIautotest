## 1. 模块一句话职责
平台"机器监控"页签(data-page=machines,导航在用例历史与验证码工具之间):经 server 只读代理 167 本机 Prometheus(127.0.0.1:9090),上下两卡展示 167(平台机)/176(构建机) CPU/内存/磁盘/网络/负载,5s 轮询+15min SVG sparkline;采集侧(Node Exporter/Prometheus/Grafana)归部署计划 §7.5 与主会话。

## 2. 部署拓扑(硬约束)
- **dashboard 与 Prometheus 同机部署在 167**(v3 重建后:167=平台机 8080,176=构建机);9090/9100 均**仅本机监听**,ufw 不放行。
- Node Exporter 167+176 各一(9100);**167 的 scrape target 是 127.0.0.1:9100**(非局域网 IP!),176 是 192.168.12.176:9100——instance 精确值见 tools/provision/monitoring-infra.md。
- Grafana :3000(167,局域网可达)是独立深度大盘,页面只放 ghost 入口链接(MC_GRAFANA_URL 常量),不内嵌 iframe(拍板)。

## 3. 数据流与 API(均在 server 独立 section)
数据流:page(激活时 summary 5s/history 30s 轮询) → /api/metrics/* → server 拼 PromQL(白名单模板,instance 精确匹配无注入面,**无任意 query 透传**) → Prometheus /api/v1/query|query_range。

| 路由 | 用途 | 降级 |
|---|---|---|
| GET /api/metrics/hosts | 机器清单 [{machine_id,instance,role}](后端配置,不做页面管理) | 恒可用 |
| GET /api/metrics/summary(无参) | **一次返回两机**全部首屏指标(设计稿 §3.2 一次 fetch 渲染两卡) | Prometheus 服务不可达→503 {"error":"监控组件未就绪","detail":...} |
| GET /api/metrics/history?machine=167[&metric=cpu][&range=15m] | 单机走势,step 15s=60 点;metric∈cpu/mem/net_up/net_down(缺省全量);range 仅 15m(P1 扩) | 同上;非法参数→400 |

summary 机器条目(2026-09-21 契约扩展+无状态化收口,设计稿 §3.3+主会话裁决):`{machine_id,role(platform|build),instance,timestamp(本条数据产出时刻 unix ts,恒有值),up(bool,本轮是否采到:target up=1 或任一核心指标有值),cpu_percent,cpu_cores,mem_percent,mem_used_bytes,mem_total_bytes(字节原值,前端换算 G),disks:[{mount,used_bytes,total_bytes,percent}],net_up,net_down(字节/秒,↑tx/↓rx),load:[l1,l5,l15],uptime_s}`——**无 status 字段,后端无状态**(不缓存、不做滞后状态机,收口裁决 2026-09-21)。
**disks 按 device 去重**(主会话裁决:数据驱动不硬凑双行)——/opt 与 / 同设备(两台机现状)只返回一行(保留根分区),不同设备才两行;查询按 (device,mountpoint) 取值,mountpoint 限定 / 与 /opt,fstype!~tmpfs|overlay。
**两级降级**:Prometheus 服务挂→503(整页"监控组件未就绪");单机 exporter 失联→该机 up=false+指标全 null,另一机照常——单机故障不拖垮整页(设计稿 §四硬要求)。**卡态全部前端判定**:up=false→红"失联"卡;timestamp 与本地时间差 >30s→黄"数据滞后"(MC_STALE_SECONDS=30)。
空态:Prometheus 刚装、rate 无数据点→指标 null,前端各格"—"+卡头"等待首次采集(约 15s)"。

## 4. PromQL 模板口径
cpu=100-avg(rate(node_cpu_seconds_total{mode="idle"}[5m]))*100;cpu_cores=count(count(...)by(cpu));mem_used=MemTotal-MemAvailable、mem_total=MemTotal(字节原值,GB 换算归前端);mem_percent=(1-MemAvailable/MemTotal)*100(与走势 "mem" 同模板);disk=filesystem_{avail,size}_bytes 按 **(device,mountpoint)** 取值,mountpoint=~"/|/opt",fstype!~tmpfs|overlay(设计稿写"device 过滤",实际按 fstype 过滤才对,tmpfs/overlay 是文件系统类型),**同 device 多挂载点在 server 内去重只留根分区**;net_up/down=sum(rate(node_network_{transmit,receive}_bytes_total{device!="lo"}[5m]));load=node_load1/5/15;uptime_s=time()-node_boot_time_seconds。

## 5. 页面 page.html(mc* 前缀)
- 导航按钮 data-page=machines(page.html nav 区);切换钩子:激活→mcStart()(立即拉+轮询),离开→mcStop()(clearInterval+重置失败节流)——轮询仅本页签激活期间(规范 5.5 例外,设计稿已括注)。
- 结构:toolbar(meta 说明+ghost 刷新+ghost Grafana 大盘)+ #mc-cards 两张卡(mcCardHtml 每 5s 全量重渲染,无 transition/动画)。单卡=卡头(状态点+角色名+负载三值/uptime[+数据时间])+四格 grid(CPU 值+核数+sparkline;内存 used/total GB+百分比(直用后端 mem_percent)+sparkline;磁盘占用条**行数跟 disks 数据走**(同设备一行/异设备两行)+percent 直用后端;网络 ↑/↓ 自动换档 KB/s|MB/s+双线 sparkline)。
- **卡态全部前端判定**(收口裁决 2026-09-21,后端无状态):`m.up===false` → 红点+chip 失联+"本轮采集未连上";`m.timestamp` 与本地差 >MC_STALE_SECONDS=30 → 黄点+"数据滞后"+卡头"数据时间 HH:MM"(滞后数字必须带时间戳);两者都否按正常渲染。
- drawSparkline(svgEl,series):原生 SVG polyline+同色 8% polygon,viewBox 120×34 拉伸;线色 CPU=--brand、内存=--good、网络↑=--brand/↓=--ink(仅分类);占用条阈值硬切 <70 --ink/70-90 --warn/>90 --bad。
- 失联卡:mc-dot bad+chip 失联(--bad-weak/--bad)+灰字"采集失联:无法连接 node_exporter(本轮采集未连上)"+ghost 重试(mcPoll);后端无状态,失联指本轮未采到。
- 连续失败≥3 次:深色 toast 一次(showToast 复用,自建 toast-box),恢复补成功 toast;503 走整页 empty 不计失败。
- MC_GRAFANA_URL 硬编码 192.168.12.167:3000(换机需改);机器清单默认 ['167','176'],进页签经 /hosts 校正。
