# 167-001 报告：laya noul 饱和诊断

## 结论（先行）
1. **根因：模型能力边界，不是推理配置问题。** noul 头只具备「短文本/单属性/粗话题」级断言核验能力（琐碎文本方向正确、能识别跨话题假声明），但对同体裁长文本（同一 App 的测试用例 标题↔内容）无细粒度语义一致性判别力，真假配对一律饱和输出 true（≈0.99）。
2. 四个候选假设全部被数据排除：中文指令不奏效 ✗、max_len 超界 ✗、声明格式 ✗、换英文检查点 ✗（详见证据表）。
3. **最优修复路线（一条）：开放语义判定（一致性/可验证性/域归类）全部转 laya-judge（.176）LLM 通道**；laya 保留给短文本属性级 noul 与强区分小选项 choice（k≤5）；不建议本地微调、不建议「翻译+EN 检查点」路线（已证与语言无关）。
4. EXP2 的 0.279：信号真实（7× 随机 0.04、≈4× 多数类基线 0.070），被 choice 头「单标签高置信塌缩」拖累（30/43 →「设备管理与配网」，错误预测置信 0.91–0.99）；且与选项数量、criteria 文本无关（k=6 反而 0.163 全塌）。域归类建议同样走 LLM 通道。

## EXP2 解读与改进（exp_diag4/6/7/8）
- 全概率重排：top1 0.279 / **top3 0.395 / top5 0.419** / true 标签中位排名 7/25；塌缩分布：设备管理与配网 **30/43**、推送/日活/版本 4、其余各 ≤2
- 标签空间收缩实验：**k=18 顶层域 0.279（与 k=25 持平）；k=6 大组 0.163（42/43 全塌到「设备与设置」）；k=6+描述性 criteria 0.163 无改善** → 拖累不是选项数、也不是裸标签名，是 choice 头对长同体裁文本+语义相邻标签的塌缩倾向
- 大 k 下 confidence 不可信（错误预测上 0.91–1.00），不得用作门槛
- 评估集病态：43 条 25 个标签（均值 1.7 条/标签），复合域含过程性后缀「/BUG回归」，文本不可分
- 改进建议：域归类走 laya-judge/LLM；若坚持 laya：只能做「检索短名单 ≤5 强区分候选 → 小 k choice」且需重做置信校准；评估先合并复合域
