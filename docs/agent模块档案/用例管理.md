## 5. 脚本:scripts/sync_cases.py
- 用法:`python scripts/sync_cases.py [--url http://192.168.12.166:8080] [--dry-run]`,默认打到 127.0.0.1:8080,逐条 PUT /api/case-defs/{id}。
- 文字用例 load_text_cases:knowledge/swan/cases/{login,fullregression,...}(排除 driver)下 YAML 的 `cases:` 列表逐条导入,strong。
- 自动化用例 load_auto_cases(返回 (items, explicit_ids)):cases/driver/** 整文件一条;关联优先级 M5 二期(2026-09-20):① frontmatter `linked_case_id`(完整文字用例编号)显式声明 strong,须全名精确命中,未命中/脏值(列表/非串/空串)打 [warn] 丢弃回退推断 ② 兜底推断:source 里 YAML 路径锁定来源文件+编号后缀唯一命中才挂,weak ③ 显式与推断不一致以显式为准打 [info];frontmatter `case_id` 仍只作 auto 自身 ID 强锚点(strong),不参与关联;dry-run 显式声明标 [explicit]。
- HTTP 重试 _post_or_put(3 次,退避 0.5s 递增;针对端口瞬时耗尽 WinError 10048)。
- driver 用例正式 schema 见 knowledge/swan/cases/driver/README-schema.md(正文 schema 由 test_case_driver.py loader 消费;linked_case_id 放 frontmatter 对 loader 透明,勿移进正文)。

## 6. 关键业务规则与坑
1. **双向关联 auto↔text**:list 单条装饰 _decorate_case_def(server.py:1176-1201)text 行挂 auto_cases[]、auto 行挂 text_case;列表批量挂 autos map(1231-1254)。页面 chip 互跳(page.html:760-765、859-863)。
2. **suites[] 装饰防 N+1**:list_case_defs 一条 SQL 批量查全部 suite_cases 挂到每行(1233-1247),改这里别退回逐行查询。
3. **模块双名**:库存 slug,展示走 modules.name_cn(module_cn),查不到回退 slug(1179-1186、1248-1256)。批量导入 module 列收中文名映射回 slug,映射不到该行 failed 不自动建模块(server.py:1143-1151)。
4. **优先级四档 P0-P3**,UI 点选+归一显示;导入模板 L1/L2/L3 自动映射(server.py:1152 复用单条校验;page.html:708)。
5. **link_strength 防冲**:upsert 只在 payload 显式携带时才更新 link_strength,否则保留原值——防止页面保存把 sync 标的 weak 冲掉(server.py:1063-1068、1100)。
6. **auto 用例编辑收窄(规范 8.5)**:编辑态 content/ID/标题/类型/source_bug 只读,可改仅优先级/模块/关联文字用例/来源描述;保存 payload 其余字段取入库快照(page.html:913-935、1021-1035)。新建 auto 用例不受限。
7. **关联规则防歧义**:driver 用例 source 里 YAML 路径先锁定来源文件,再按编号后缀匹配,**唯一命中才挂** linked_case_id,FR-L2-POS-002/LOGIN-L2-POS-002 这类多命中不挂(sync_cases.py:131-147);bug 单 SWAN-BUG-* 从 tags/标题/source 提取(29、91、148)。
8. **执行历史当时快照不回写**:用例历史页查 /api/cases/{case_id}/history(server.py:1773-1785,JOIN runs/cases),记录执行当时的 status/设备/包体快照;case_defs 修改后历史不追溯回写。case_defs.case_id 与 cases.case_id 同一编号空间,抽屉/详情无历史入口,跳历史在 page-cases。
9. **坑**:delete_case_def 已修复(2026-09-20)——删除用例时同事务先 `DELETE FROM suite_cases WHERE case_id=?` 再删用例(SQLite FK 仍未启用),返回 removed_suite_members;delete_test_suite 手动级联(1481-1490)。列表 limit 上限 1000,超 1000 条用例需改服务端分页。改 page.html JS 用 `node --check` 验不了(html),需抽 JS 段或浏览器自测;$() 引用与函数定义要交叉核对。弹层显隐统一 hidden 属性,勿写内联 display。

## 7. 模块边界
- **流水线调度**:pipeline_configs.suite_id 引用 test_suites;list_suite_case_paths(server.py:1492-1523)按 seq 取 enabled=1 成员的 file_path 供聚合 pytest 目标(YAML driver 用例→pytest 映射待 M5,调用方自行按后缀过滤)。流水线页套件下拉实时拉 /api/suites(page.html:1511)。
- **执行会话/用例历史/禅道**:runs/cases 两表属执行域;本模块只通过编号空间(case_id)关联,无外键。
- **包管理**:无直接接触。
- **sync_cases.py → 平台**:走 HTTP PUT(可指向 .166),属部署侧数据流,不主动全量重跑。
