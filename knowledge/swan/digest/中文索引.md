# Swan 知识库中文索引（人读入口）

> 阅读用。page_id 即中文页面名（= `pages/` 下文件名去掉 .md）；程序与 agent 检索以 `app_map.json`、`[[双向链接]]`、MCP 图谱查询为准。
> 元素 key（如 `tab_me`）是 App 开发定义的 accessibility resource-id，来自真机 dump，**不可翻译**；每个 key 的中文含义见对应页面文档的关键元素表。

## 无 key 页面提示

家庭管理 / SWAN收藏 / 音质设置弹层 / 收藏分组详情页 / 帮助与反馈页 / 关于与升级页 全页无 accessibility key（收藏分组详情页仅有 bottom_player），自动化定位走 OCR `click_text`（中文文案）或上表图像模板。

首页四顶 Tab（音乐/电台/AI/可视音箱）/ 扫一扫 / 资料编辑 / 区号选择 / 我的页列表行 同样无 key，走 OCR 或图像模板。⚠️ 首页顶部 Tab 选择跨底栏切换、跨登出/登录持久保留——`go_home()` 只回首页容器不重置顶 Tab，进推荐 Tab 须显式点 OCR"推荐"。
