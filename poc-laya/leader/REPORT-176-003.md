# 176-003 报告：torch 下载换源提速 —— 结论：镜像皆不可用，wheelhouse 抢救+官方源完成

## 结论
清华、阿里云 pytorch-wheels 镜像**均无法用于本机 torch cu126 安装**；最终方案 =
**抢救旧运行残留 wheel（1.94GB）+ 官方源补缺（~29 分钟）**，15:59:58 ALL_DEPS_DONE。
torch 2.14.0+cu126 + laya 0.3.5 装毕，cuda.is_available()=True。

## 各源实测
| 路径 | 结果 |
|---|---|
| 清华 pytorch-wheels/cu126 | **404**（该子目录不存在，pip "from versions: none"） |
| 阿里云 pytorch-wheels/cu126 `--index-url` | 页面存在且含 1298 个 wheel 锚（含 torch-2.14.0+cu126-cp312），**pip 26.2.1 解析不出任何版本** |
| 阿里云同页 `--find-links --no-index` | 能解析并开始下载，但**实测传输 ~0.06-0.1MB/s**（869MB 主包 10 分钟仅 35MB），比官方源慢 10 倍，放弃 |
| 官方 download.pytorch.org/whl/cu126 | 1-1.7MB/s，稳定 |

## 关键操作
1. 停旧管道：原安装链为 `pip cu126 || pip cu124; pip install laya; echo ALL_DEPS_DONE`（`;` 连接），
   只杀 pip 会误触发 cu124 二次大下载+假完成标记 → **连同父脚本一起杀**（95341/95342）。
2. **wheelhouse 抢救**：旧运行已在 /tmp/pip-unpack-* 留下完整 wheel，zip 完整性校验后入
   `~/laya-judge/wheelhouse/`（10 个，1.94GB：cudnn 674M/cublas 375M/nccl 276M/cusparselt 274M/
   cufft 191M/nvshmem 133M/nvjitlink 38M 等；torch、curand 残缺弃用）。
3. 两阶段安装：先本地直装 wheelhouse（同版本号即满足 torch 精确 pin；注意 find-links 与 index
   同版本时 index 优先、不会跳过下载，必须先装），再官方源装 torch —— 只补缺（cusolver/cusparse/
   curand/nvrtc/triton/torch ≈1.55GB，实测 1.7MB/s）。
4. laya 0.3.5 从默认 pypi 安装（含 transformers 5.17.0），15:59:58 完成。
   教训：pkill -f 模式含在自己命令行里会自杀（144），任务文件预警过的坑应验。
