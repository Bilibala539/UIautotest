新项目上 web 端时：复用 WebBaseAW 全部基础操作，只需新增 business/<新项目>.py 和对应 <新项目>User，基础层零改动。

目录规划（目标态）

utils/
├── otp_client.py                 # 验证码客户端（纯 HTTP）
├── user.py                       # User 基类 + TTUser / SwanUser / ??User
└── aw/
    ├── aw_base.py                # 公共引擎：OCR/截图/图像匹配（一份）
    ├── base/                     # ★ 基础 AW 按端分
    │   ├── __init__.py
    │   ├── web_base.py           # WebBaseAW(AWBase)
    │   ├── android_base.py       # AndroidBaseAW(AWBase)
    │   └── flutter_base.py       # FlutterBaseAW(AndroidBaseAW)
    └── business/                 # ★ 业务 AW 按项目分
        ├── __init__.py           # 工厂
        ├── common.py             # CommonBusinessMixin（跨项目公共：otp/wait_text/login骨架）
        ├── tiditree.py           # TidiTreeBusiness（原 web.py）
        ├── swan.py               # SwanBusiness
        └── android_project.py    # ??Business（安卓项目，名字待定）

调用链示例：SwanUser 验证码登录

sequenceDiagram
    participant T as 用例 (tests/flutter/)
    participant U as SwanUser
    participant SB as SwanBusiness
    participant FB as FlutterBaseAW
    participant AW as AWBase 引擎

    T->>U: userA.login_by_sms(userA.phone)

    FB->>AW: find_text_by_ocr / tap
    SB->>OTP: otp.get_code(phone)
    OTP->>GW: GET /api/test/otp/latest?phone=…
    GW-->>OTP: pull 开发接口 mockCode → 返回验证码
    OTP-->>SB: {code: "123456"}
    SB->>FB: input_text(code) / click_accessibility(...)
