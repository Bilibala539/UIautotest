# TidyTree Android 平台概况

## 建模范围

本知识库只描述 TidyTree Android App 的原生页面、弹窗、系统权限界面、导航转场和可复用测试状态。Web 页面、URL、DOM 选择器和浏览器窗口信息属于 `explorer_output/knowledge/`。

## 待确认的平台信息

| 项目 | 当前值 | 记录要求 |
|---|---|---|
| 应用包名 | 未确认 | 从 APK/ADB 实际信息填写 |
| 启动 Activity | 未确认 | 从实际启动流程填写 |
| Android 版本 | 未确认 | 记录测试设备版本 |

| 默认方向 | 未确认 | 按页面实际状态记录 |
| 登录方式 | 未确认 | 只记录环境变量名，不记录凭据 |

## 首次探索建议

1. 连接并确认目标设备，保存设备上下文。
2. 从冷启动开始，按页面/弹窗边界建立 `draft/*.md`。
3. 为每个页面记录稳定 resource-id、content-desc、文本和关键 UI 状态。
4. 记录页面之间的前置条件、操作、成功断言和副作用。
5. 真机复测通过后转正到 `pages/`，再更新索引和反向链接。
