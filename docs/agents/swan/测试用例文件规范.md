# Swan 测试用例文件规范（强制遵守）

> 适用范围：Swan 项目（tests/flutter/）。其他项目参照 CLAUDE.md 规则 8 与本模板。
> 2026-10-13 修订：①setup/teardown 必须显式声明（super 调用 mixin）；②**严禁 @pytest.mark.parametrize**——数据变体各自独立成文件（值写死在用例里），模块级参数表同禁；③平台/账号门禁由 conftest hook 统一处理，用例文件禁止写 _platform/_has_phone/pytestmark skipif。
> 2026-10-14 修订：④用户对象方法必须静态可解析（IDE Ctrl+点击直达声明，见强制条款 8）；⑤**冷启动模型**——App 冷启动由框架夹具承担（conftest `_cold_start_swan_app`），teardown 显式声明但 body 一律 `pass`，**禁止 `super().teardown()`**（mixin teardown 已退役，见强制条款 2）。
> 2026-10-15 修订：⑥**值直接内联进调用**——禁止先赋中间变量再作实参传入（`platform = 'netease'` + `open_platform_entry(platform, ...)` 式写法），见强制条款 9。

## 强制条款

1. **一用例一文件一 test 方法（铁律）**：每个用例 .py 文件**有且仅有一个 `test_` 方法**；不同测试场景、**不同数据变体**各自独立成文件（值写死在用例里）。**严禁使用 `@pytest.mark.parametrize`**（用户 2026-10-13 拍板：参数装饰器=一个文件跑多条，等价于一文件多用例）；模块级参数表变量同禁（HISTORY_KINDS/ENTRIES 式）。例外仅限 `tests/flutter/test_case_driver.py`（平台 YAML 用例执行载体）（CLAUDE.md 规则 8）
2. **固定方法名**：用例类中必须**显式**声明 `setup()` 与 `teardown()`（conftest `_auto_test_lifecycle` 自动调用）。`setup()` 逻辑为实例化用户对象；`teardown()` body 一律 `pass`（冷启动模型：App 冷启动由框架夹具承担，见 conftest `_cold_start_swan_app`）——**仅用例私有清理才写实际逻辑，禁止 `super().teardown()`**（mixin teardown 已退役，CLAUDE.md 规则 12）
3. **禁止 Page Object 模式**：业务流程通过业务方法编排（如 `self.user.start_play()`）
4. **用户实例化只在 setup()**：`self.userA = self.users("swanuserA")`——用户对象承载全部用户信息（info 字典），全程 `self.userA.xxx()` 直调（无 self.aw 中间层；模型见 `对象模型与调用关系.md`）；多用户 users("swanuserB")
5. **基础操作不堆在用例里**：缺业务动作 → 加到 `SwanBusiness`；用例间共用的前置/清理编排 → 放业务层 `utils/aw/business/swan_regression.py`（mixin），不在用例间复制粘贴
6. **定位与断言**：图像模板 > OCR 文本；accessibility key 仅限探索辅助（explorer），运行时用例禁止 key（CLAUDE.md 规则 2）；断言以可观察状态收尾，禁止"只断言没异常"
7. **平台/账号门禁由框架统一处理**：conftest `pytest_collection_modifyitems` 自动对 tests/flutter 下用例做 PLATFORM/SWAN_PHONE/SWAN_PASSWORD（密码域）skip——**用例文件禁止写模块级环境探测行与 pytestmark skipif**；用例级状态条件（如授权态）用方法内 `pytest.skip` 表达
8. **用户对象方法必须静态可解析（IDE 跳转可达）**：`self.userA.xxx()` 每个调用都要能 Ctrl+点击直达声明——业务方法必须定义在 SwanBusiness MRO（含 mixin）上（机制：`utils/user.py` TYPE_CHECKING 静态视图 + conftest `users()` overload，CLAUDE.md 规则 11）。mixin 未挂入 MRO 的方法 userA 调不到也看不到（运行时 AttributeError）；禁止 `self.userA.<拼错名>`、禁止对 userA 的只读 property（phone/password/package）赋值
9. **值直接内联进调用**：调用业务方法的常量实参**直接写在调用处**（位置实参或带入参名的关键字实参均可），**禁止先赋中间变量再传入**（2026-10-15 拍板）：
   - ❌ `platform = 'netease'` + `self.userA.open_platform_entry(platform, entry, expect_title)`
   - ✅ `self.userA.open_platform_entry('netease', '歌单', '歌单')` 或 `open_platform_entry(platform='netease', entry='歌单', expect_title='歌单')`
   - 例外：**运行时数据**变量（`os.environ.get(...)` 结果、方法返回值、按条件分支计算值）不属此类，正常使用；常量驱动的死分支须按文件内的实际值展开成直线代码（不做恒真/恒假判断）

## 标准测试用例模板

```python
"""
Swan 回归·<域>：<用例名>（回归用例 <编号>）。

用例 -> AW 映射（docs/Swan回归用例AW实现方案.md §2.3 域N）：
- <步骤/断言对应关系>
清理（G3/G4）：由 mixin teardown 承担（关弹层 -> 尽力暂停 -> 收播放页 -> 回首页）。
"""
from __future__ import annotations

import pytest

from conftest import BaseTest
from utils.aw.business.swan_regression import SwanPlayerRegressionMixin

# ⚠️ 禁止：模块级 _platform/_has_phone 探测、pytestmark skipif、参数表变量——
# 平台/账号门禁由 conftest hook 统一处理；数据变体独立成文件（禁 parametrize）


class TestXxx(SwanPlayerRegressionMixin, BaseTest):
    """<用例名>。"""

    def setup(self) -> None:
        """测试前初始化：实例化用户对象（用户信息挂在 userA 上）。"""
        self.userA = self.users("swanuserA")

    def test_xxx_scenario_speaker(self):
        """<测试场景描述>（变体：手机扬声器；其他变体各自独立成文件）。"""
        device_type = "speaker"             # 变体值写死在用例里（禁 parametrize）
        self.userA.preset_playing(device_type)   # 共用前置：登录 -> 导航 -> 发起播放
        self.userA.assert_playing()         # 业务方法断言收尾

    def teardown(self) -> None:
        """无用例私有清理（冷启动模型：App 冷启动由框架夹具承担）。"""
        pass
```


## 禁止事项

- ❌ 一个 py 文件多个 test 方法（铁律，CLAUDE.md 规则 8）
- ❌ `@pytest.mark.parametrize`（禁用——变体独立成文件）
- ❌ 模块级参数表变量（HISTORY_KINDS/ENTRIES 式——同禁）
- ❌ 用例文件里的 `_platform = os.environ...` 探测行与 pytestmark skipif（conftest hook 统一处理）
- ❌ setup/teardown 省略不写，或 `setup_method` 等变体命名
- ❌ teardown 里写 `super().teardown()`（冷启动模型下 mixin teardown 已退役——body 一律 pass，仅私有清理才写实际逻辑）
- ❌ `LoginPage` 式 Page Object
- ❌ 用例中手写 login()/logout() 幂等前置（复用业务层/ mixin）
- ❌ 用例里堆基础操作序列（该沉淀进 SwanBusiness 的沉淀进去）
- ❌ try/except 吞断言失败
- ❌ 调用静态视图解析不到的 userA 方法（mixin 未挂 SwanBusiness MRO / 方法名拼错——IDE Ctrl+点击"找不到声明"即违规，CLAUDE.md 规则 11）
- ❌ 常量实参经中间变量转发（`x = 'netease'` + `f(x)`——值直接写进调用，见强制条款 9）
