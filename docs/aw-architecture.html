新项目上 web 端时：复用 WebBaseAW 全部基础操作，只需新增 business/<新项目>.py 和对应 <新项目>User，基础层零改动。

维护规则

公共引擎 (aw_base.py)只写一份，不要往回加端专属操作
端专属基础操作web → base/web_base.py；android → base/android_base.py；flutter → base/flutter_base.py
跨项目通用业务（Mixin）business/common.py
项目专属业务business/tiditree.py | android.py | swan.py；新项目 = 新增 <项目>.py + <项目>User + conftest 分发一行
纯 HTTP 外部依赖放 utils/ 独立客户端，由业务层调用
user 类只做会话关联与代理，不要在 user 类里写业务实现
跨项目调用天然 fail fast：TidiTree 用例调 Swan 方法 → AttributeError
